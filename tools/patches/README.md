# Για το παλιό αποθετήριο GrandOfficersVisitsRepresentGM

Η σελίδα Δηλώσεων ζει πλέον στο `declarations/` αυτού του αποθετηρίου (με όλες τις διορθώσεις).
Για να «σβηστεί» η παλιά σελίδα χωρίς να χαθούν παλιοί σύνδεσμοι: αντικαταστήστε το `index.html` του
`NGLG-GSEC/GrandOfficersVisitsRepresentGM` με το `GrandOfficersVisitsRepresentGM-redirect/index.html`
(ανακατευθύνει στη νέα διεύθυνση) ή αρχειοθετήστε το αποθετήριο από τις ρυθμίσεις του στο GitHub.
Το `*.patch` κρατιέται μόνο ως ιστορικό των αλλαγών.
