Τρεις λογαριασμοί Google:

| 👤 | Λογαριασμός | Ρόλος |
|---|---|---|
| **INFO** | info@nglgreece.gr | Κάτοχος του Apps Script της Πύλης — **από αυτόν φεύγουν όλα τα email** (κωδικοί, αλλαγές, αναγγελίες) |
| **GS** | grand.secretary@nglgreece.gr | Επίσημος λογαριασμός Μ. Γραμματέα — super admin, παραλήπτης αναγγελιών |
| **ΠΡΟΣΩΠΙΚΟΣ** | ο προσωπικός Gmail του Μ. Γραμματέα | super admin (σύνδεση με κωδικό στο email) |

Η εφαρμογή (https://nglg-gsec.github.io/NGLG-Grand-Secretary/) συνδέεται με **GitHub**, όχι με Google· ανοίγει σε όποιο προφίλ
browser είναι ήδη συνδεδεμένη. Η «Σύνδεση με Google» της Πύλης **δεν χρειάζεται**: όλοι μπαίνουν με κωδικό μιας χρήσης στο email.

## Α. Apps Script της Πύλης — 👤 INFO

1. https://script.google.com/home?authuser=info@nglgreece.gr (πάνω δεξιά πρέπει να φαίνεται το info@).
   Ανοίξτε το έργο «Πύλη Γραμματέων Στοών» (ή **New project** με αυτό το όνομα).
2. Code.gs: σβήστε τα πάντα και επικολλήστε https://raw.githubusercontent.com/NGLG-GSEC/NGLG-Grand-Secretary/main/lodge/apps-script/Code.gs → 💾.
3. ⚙ Project Settings → Script Properties:
   - `SUPER_ADMINS` = οι λογαριασμοί διαχειριστών χωρισμένοι με κόμμα (GS, ΠΡΟΣΩΠΙΚΟΣ και όποιον άλλο)
   - `ANNOUNCE_EMAILS` = grand.secretary@nglgreece.gr
4. Code.gs → συνάρτηση `testSetup` → ▶ Run → άδεια με **info@** → πρέπει να έρθει «Δοκιμή — Πύλη Γραμματέων Στοών» σε κάθε διαχειριστή.
5. Deploy → **Manage deployments** → ✏️ → New version → Deploy (το URL μένει ίδιο). Πρώτη φορά: **New deployment** → Web app,
   Execute as **Me (info@)**, Who has access **Anyone** → το URL `…/exec` στον Μ. Γραμματέα / στο `lodge/config.js`.

## Β. Εφαρμογή — 👤 όποιο προφίλ έχει την εφαρμογή συνδεδεμένη (GitHub)

1. **Email Στοών στη βάση:** https://nglg-gsec.github.io/NGLG-Grand-Secretary/#/lodges → «Εισαγωγή / ενημέρωση από Excel» →
   επικόλληση του πίνακα «ΣΤΟΑ ΥΠ. ΑΡΙΘΜ. · email · Low1» (με την επικεφαλίδα) → Εισαγωγή. Τα email Επαρχιών είναι ήδη στη βάση.
2. https://nglg-gsec.github.io/NGLG-Grand-Secretary/#/lodge-portal → ⚙ Ρύθμιση → URL `…/exec` → Αποθήκευση.
3. 🔐 Σύνδεση διαχειριστή → email διαχειριστή → ✉ Αποστολή κωδικού → ο κωδικός έρχεται **από info@** → ✓ Επιβεβαίωση.
4. **⬆ Δημοσίευση μητρώων** (όλες οι Στοές με email).
5. https://nglg-gsec.github.io/NGLG-Grand-Secretary/#/lodge-secretaries → **⬆ Δημοσίευση στις Επαρχίες**.
