# Υποδομή της εφαρμογής: πού βρίσκεται τι και πώς αλλάζουν οι κωδικοί

> Το αποθετήριο είναι **δημόσιο**: εδώ δεν γράφονται ποτέ τιμές κωδικών, κλειδιά (tokens) ή προσωπικά email.
> Οι κωδικοί υπάρχουν μόνο στις κρυφές ρυθμίσεις (Script Properties) του Google Apps Script
> ή στο ιδιωτικό αποθετήριο δεδομένων.

```
Σελίδα Δηλώσεων (declarations/, GitHub Pages)
   └─ καλεί → Apps Script (/exec)  ── Script Properties: ADMIN_KEY · ADMIN_EMAILS · GOOGLE_CLIENT_ID

```

## 2. Πώς αλλάζουν οι κωδικοί (Google Apps Script)

**Κωδικός της Διαχειριστικής Αναφοράς των Δηλώσεων (`ADMIN_KEY`):**

1. Συνδεθείτε στο Google με τον λογαριασμό που έχει το Sheet «Δηλώσεις Εκπροσώπησης Μ.Δ.».
2. Ανοίξτε το Sheet → **Επεκτάσεις (Extensions) → Apps Script**.
3. Αριστερά ⚙️ **Ρυθμίσεις έργου (Project Settings)** → κάτω **Script Properties** → **Edit script properties**.
4. Αλλάξτε την τιμή του `ADMIN_KEY` (ή **Add script property** αν δεν υπάρχει) → **Save script properties**.
5. Ισχύει αμέσως· **δεν** χρειάζεται νέα ανάπτυξη (Deploy).

**Λογαριασμοί που μπαίνουν με «Σύνδεση με Google» χωρίς κωδικό (`ADMIN_EMAILS`):**
ίδια θέση, ιδιότητα `ADMIN_EMAILS`, τιμή: email χωρισμένα με κόμμα. Ισχύει αμέσως.
Ο κώδικας (από την έκδοση 3 του Code.gs) δεν έχει έτοιμη λίστα: χωρίς `ADMIN_EMAILS` η αναφορά ανοίγει μόνο με τον κωδικό.

**Google Client ID (`GOOGLE_CLIENT_ID`):** ίδια θέση· η τιμή από Google Cloud Console → APIs & Services → Credentials.

**Έλεγχος:** ανοίξτε στον browser το URL `/exec` του script (υπάρχει στο `declarations/index.html`, `API_URL`).
Δείχνει `version`, `adminKey: "ρυθμίστηκε" | "ΛΕΙΠΕΙ"`, `adminEmails: <πλήθος>` — ποτέ τις τιμές.

**Όταν αλλάζει ο κώδικας του Code.gs** (όχι οι κωδικοί): αντικαταστήστε το περιεχόμενο στο Apps Script →
**Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. Το URL `/exec` μένει ίδιο.
Πρώτα ορίζονται οι Script Properties, μετά ο νέος κώδικας.

## 3. Άλλοι κωδικοί / πρόσβαση της εφαρμογής

- **Είσοδος χρηστών (email + κωδικός):** προσωπικός σύνδεσμος από Ρυθμίσεις → «👤 Πρόσκληση χρήστη»· ο κωδικός δεν αποθηκεύεται πουθενά. Για νέο κωδικό: νέα πρόσκληση.
- **Διαχειριστής εφαρμογής:** σύνδεση με κλειδί GitHub (token) του οργανισμού NGLG-GSEC (GitHub → Settings → Developer settings → Personal access tokens).
- **Drive/Gmail:** δεν έχουν κωδικό στην εφαρμογή· ζητείται σύνδεση Google στο αναδυόμενο παράθυρο.
  **Σωστό προφίλ: `info@nglgreece.gr`** (για Drive και Gmail). Η εφαρμογή το προτείνει αυτόματα (Ρυθμίσεις → «Λογαριασμός Google για το Drive»
  και ο λογαριασμός αποστολής του Gmail). Ποτέ @gmail.com: το έργο Google είναι Internal.
  Το info@ χρειάζεται δικαίωμα **Επεξεργασίας** στον φάκελο «Εξερχόμενα 2026» (κοινή χρήση από τον ιδιοκτήτη grand.secretary@).

## 4. Σημείωση για το μέλλον

Οι Δηλώσεις (Sheet + Apps Script) ανήκουν σε προσωπικό λογαριασμό. Για μεταφορά στο grand.secretary@nglgreece.gr:
αντίγραφο του Sheet από τον νέο λογαριασμό → επικόλληση Code.gs στο Apps Script του αντιγράφου → Script Properties →
Deploy (Web app, Execute as: Me, Access: Anyone) → το νέο URL `/exec` στο `API_URL` του `declarations/index.html`.
