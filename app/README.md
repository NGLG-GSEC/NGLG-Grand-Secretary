# Ψηφιακή Μεγάλη Γραμματεία

Η εφαρμογή της Μεγάλης Γραμματείας της ΕΜΣτΕ. Τρέχει **μόνο στο GitHub**, χωρίς διακομιστή, χωρίς Render και χωρίς
άλλες υπηρεσίες, και δεν έχει κόστος.

- **Εφαρμογή:** https://nglg-gsec.github.io/NGLG-Grand-Secretary/app/ (GitHub Pages, ανοίγει αμέσως)
- **Δεδομένα:** ιδιωτικό αποθετήριο `NGLG-GSEC/nglg-grammateia-data` (μία κοινή βάση για όλες τις σελίδες).
  Κάθε αλλαγή κρατιέται στο ιστορικό του GitHub, ώστε να φαίνεται ποιος άλλαξε τι και να γίνεται επαναφορά.

## Πρώτη χρήση (μία φορά, περίπου 2 λεπτά)

1. **Μία φορά για όλους:** δημιουργήστε το ιδιωτικό αποθετήριο δεδομένων:
   https://github.com/new?owner=NGLG-GSEC&name=nglg-grammateia-data&visibility=private
   Επιλέξτε **Private** και πατήστε «Create repository».
2. **Σε κάθε συσκευή:**
   - ανοίξτε την εφαρμογή και, στην ενότητα «Πρώτη φορά;», πατήστε «Δημιουργήστε κωδικό πρόσβασης»;
   - πατήστε «Generate token» και αντιγράψτε τον κωδικό, που ξεκινά με `ghp_`;
   - επικολλήστε τον και πατήστε «Σύνδεση».

   Ο κωδικός μένει μόνο σε αυτή τη συσκευή.
3. **Μεταφορά των παλιών δεδομένων:**
   - στην παλιά εφαρμογή (Render) πηγαίνετε στη Βάση Δεδομένων → «💾 Αντίγραφο ασφαλείας» → «Λήψη πλήρους αντιγράφου»;
   - στη νέα εφαρμογή πηγαίνετε στη Διαχείριση → «💾 Αντίγραφο & μεταφορά δεδομένων» → «Εισαγωγή» με το αρχείο αυτό.

   Από την ίδια σελίδα εισάγονται και τα αρχεία `.json` της σελίδας «Επιστολές Γραμματείας».

## Τι κάνει

| Ενότητα | Αρχείο κώδικα |
|---|---|
| Επιστολές (ενιαίο πρωτόκολλο, έντυπο Α4, PDF, Gmail, WhatsApp), Πρότυπα | `modules/letters.js`, `modules/protocol.js` |
| Διατάγματα (ΔΙΟΡΙΖΟΜΕΝ / ΑΠΟΝΕΜΕΙ / ΕΥΑΡΕΣΤΟΥΜΕΘΑ) → Επετηρίδα | `modules/decrees.js`, `modules/decree-catalog.js` |
| Μητρώο Μελών (αναζήτηση, Excel) | `modules/members.js` |
| Επετηρίδα | `modules/epeteirida.js` |
| Συμβολικές Στοές, Επαρχίες (ΕπΜΔ, ΕπΜΓρ.), Κατάλογος | `modules/lodges.js`, `modules/provinces.js`, `modules/directory.js` |
| Επισκέψεις Στοών, Εκπρόσωποι ΜΔ, ενημέρωση Επαρχίας, προσκλήσεις ημερολογίου | `modules/visits.js` |
| Εορτολόγιο & ευχές με την πλακέτα, αναφορά στον ΜΔ | `modules/namedays.js` |
| Πρότζεκτ ΜΔ (με φωτογραφίες/PDF) | `modules/projects.js` |
| Βάση Δεδομένων, Βιβλίο Πρωτοκόλλου, αντίγραφο & μεταφορά | `modules/database.js` |

| Αρχική, μενού, Υπογράφων | `modules/home.js` |

**Email:** κάθε μήνυμα ανοίγει έτοιμο στο Gmail, με παραλήπτες, θέμα και κείμενο, από τον σωστό λογαριασμό:
- `grand.secretary@` για Επιστολές και Διατάγματα;
- `info@` για όλα τα υπόλοιπα.

Εσείς πατάτε μόνο «Αποστολή».

**PDF:** «PDF / Εκτύπωση» → «Αποθήκευση ως PDF». Τα ελληνικά εμφανίζονται σωστά σε κάθε συσκευή.

## Για αλλαγές στον κώδικα

- Δεν χρειάζεται εγκατάσταση ή «χτίσιμο». Είναι απλά αρχεία HTML/CSS/JavaScript, και κάθε αλλαγή στο `main` δημοσιεύεται
  αυτόματα στο GitHub Pages.
- **Μία ενότητα = ένα αρχείο** στο `modules/`. Κάθε ενότητα δηλώνει τις σελίδες της με `module({...})`.
  Το μενού ορίζεται σε ένα σημείο (`modules/home.js`), και η Αρχική συγκεντρώνει αυτόματα τα πλακίδια κάθε ενότητας.
- Ο **πυρήνας** στο `core/` είναι κοινός για όλες τις ενότητες:

  | Αρχείο | Τι κάνει |
  |---|---|
  | `store.js` | η βάση: πίνακες, αποθήκευση/συναλλαγές |
  | `backend.js` | GitHub ή τοπική αποθήκευση |
  | `app.js` | σελίδες, μενού, φόρμες |
  | `crud.js` | λίστα/επεξεργασία/Excel για απλούς πίνακες |
  | `paper.js` | επίσημο έντυπο Α4 |
  | `mail.js` | Gmail |
  | `pickers.js` | επιλογή μέλους/επαφής |
  | `util.js` | εργαλεία |

- **Βάση:** κάθε πίνακας είναι ένα αρχείο `data/<πίνακας>.json` στο ιδιωτικό αποθετήριο.
  - Οι ρυθμίσεις είναι στο `data/settings.json` και τα αρχεία των Πρότζεκτ στο `files/projects/`.
  - Κάθε αποθήκευση είναι μία συναλλαγή. Αν στο μεταξύ αποθήκευσε κάποιος άλλος, η εφαρμογή φορτώνει τα νέα δεδομένα και
    ξαναεφαρμόζει την αλλαγή, ώστε ο αριθμός πρωτοκόλλου να μη διπλασιάζεται ποτέ.
- **Έλεγχοι:** `python -m pytest app/tests` (Playwright/Chromium). Τρέχουν και αυτόματα στο GitHub σε κάθε αλλαγή.
  - Ελέγχεται κάθε ενότητα, η αποθήκευση στο GitHub με προσομοίωση, οι ταυτόχρονες αλλαγές, η μεταφορά από την παλιά
    εφαρμογή, οι σύνδεσμοι του portal και η προβολή σε κινητά.
  - Στην εφαρμογή, η σελίδα **🩺 Έλεγχος εφαρμογής** ανοίγει όλες τις σελίδες και δείχνει ✓/✗.

## Ασφάλεια

- Το αποθετήριο του κώδικα είναι δημόσιο, γι' αυτό **δεν περιέχει κανένα προσωπικό δεδομένο**.
  Μέλη, email και κινητά βρίσκονται μόνο στο ιδιωτικό αποθετήριο δεδομένων.
- Η εφαρμογή αρνείται να συνδεθεί αν το αποθετήριο δεδομένων είναι δημόσιο.
- Ο κωδικός πρόσβασης GitHub αποθηκεύεται μόνο στον browser της συσκευής. «Αποσύνδεση» από τις Ρυθμίσεις.
